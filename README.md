## Algunos proyectos que cuentan mi recorrido


### 🏠 Inversión turística en Málaga

Dashboard para analizar la actividad de los alojamientos turísticos de Málaga y encontrar señales útiles para la toma de decisiones.

**Mi trabajo:** preparación y análisis de los datos, creación de métricas y desarrollo del dashboard en Power BI.

🔗 [Ver proyecto](https://github.com/Gema-Villanueva/dashboard-inversion-malaga)

---

### 🥇 Golden Forecast

Proyecto de Machine Learning para predecir el movimiento del precio del oro y generar una señal de compra, venta o espera.

**Mi aportación:** preprocesamiento, creación de variables, definición del target, documentación y trabajo colaborativo mediante ramas y pull requests.

🔗 [Ver proyecto](https://github.com/juandelaf1/Golden-Forecast)

---

### 🍷 InWine · Sommelier IA

Sistema de recomendación de vinos que combina preferencias, ocasiones y características de cada vino para ayudar a elegir mejor.

**Mi aportación:** análisis con PCA, preparación del pipeline, documentación y revisión del trabajo en equipo.

🔗 [Ver proyecto](https://github.com/MajoRodri/InWine)

---

### 🌦️ WeatherLy

Aplicación en Python que consulta datos meteorológicos, guarda la información y genera alertas según las condiciones del tiempo.

**Lo que trabajamos:** conexión con APIs, validación, almacenamiento, organización modular del código y pruebas.

🔗 [Ver proyecto](https://github.com/SiRON/Bootcamp_Proyecto_2_WeatherLy)
